# 2026 부동산 트렌드 — 인사이트 정리 & 한지 서비스 반영 로드맵

> 책 『2026 부동산 트렌드』 페이지 사진 27장을 6개 배치로 시각 분석(도표·지도·표) → 분석 가치가 있는 인사이트만 선별하고, 각각을 한지의 실거래 데이터(2024-06~2026-06, 서울/경기/인천)로 재현·기능화할 수 있는지 정리.

## 핵심 방법론 (책의 뼈대)
저자의 분석은 두 축으로 요약된다.
1. **이동평균 교차 신호** — 실거래를 주간 가격지수(AVM)로 지수화한 뒤 **7주(단기)·24주(중기) 이동평균선**을 그어 **골든크로스(상승 진입)/데드크로스(하락 시작)** 로 매매 타이밍을 포착.
2. **상승 도미노(전파)** — 가격 상승은 강남에서 시작해 인접 지역으로 **시차를 두고 순차 전파**된다. 권역별 순차 회복 lag로 "다음 상승 지역"을 예측.

이 두 축은 **한지의 실거래만으로 100% 재현 가능**하며 가장 강한 차별화 기능이 된다.

## ★★ 현재 데이터만으로 가능한 것 (냉정한 분류)
> 판단 기준: **외부 데이터 적재·지오코딩 없이, 지금 `실거래_테이블`(2024-06~2026-06)만으로** 만들 수 있는가. (데이터는 수도권 중심 + 부산·대구·충북 등 일부 지방 포함, 앱 스코프는 수도권)

**우리가 가진 것**: 시군구·읍면동 코드 / 단지명 / 물건유형(아파트·빌라) / 거래유형(매매·전세) / 계약일자 / 전용면적 / 층 / 건축연도 / 거래금액·보증금·월세.
**없는 것**: 좌표·지오코딩, 세대수, 소득, 인구·세대 통계, CPI, 공급·착공, 지하철·업무지구 위치.
**무효 필드**: 가격이상치(항상 false), 거래경위(전부 null), 단지코드(전부 null) — 쓸 수 없음.

## 서비스 반영 로드맵 (재현가능성 × 임팩트 × 페르소나 정합)

### Tier 1 — 실거래만으로 즉시, 임팩트 높음
1. **신고가 대표성 배지** (IMG_4205) — 단지/지역 상세에 "최고가 vs 중위값" 병기 + 경고("최근 90일 중 1건, 중위 대비 +45%"). 기존 이상치 탐지 강화. **난이도 낮음.**
2. **이동평균 골든/데드크로스 스캐너** (IMG_4214/4216) — 자치구·권역 평당가 시계열에 7주·24주(또는 데이터 길이에 맞춘 6주·24주) 이평선 → 크로스 자동 탐지. 히트맵에 "골든크로스 발생 구" 배지 + 단지추천 '모멘텀' 점수 연동. ※2년(≈104주)뿐이라 **단지 단위보다 자치구/권역 집계**가 안정적.
3. **주거 부담 계산기** (IMG_4209) — 연소득·LTV·금리·기간 입력 → 월 상환액(원리금/이자) → **상환 가능한 실거래 매물 필터**. 예산매물·가성비 추천에 연결.
4. **예산→평균 연식 매트릭스** (IMG_4222) — 전세가율 히트맵 구조 재사용. "이 예산이면 대략 몇 년식" 배지.

### Tier 2 — 재현 가능, 중간 난이도
5. **상승 도미노 타임랩스 + 시차상관** (IMG_4215/4212/4227) — 히트맵 24개월 월별 슬라이더 재생 + 자치구 간 lag correlation으로 "다음 상승 후보 구" 추천. 권역비교에 강남3구/강북3구 프리셋.
6. **자산 집중 벨트 맵** (IMG_4201/4204) — 평당가 상위5%/하위5% 단지 이중 산점 오버레이 + 최근접거리 집적도 지수. 세대당 가액 랭킹(평당가×전용면적; 총액 랭킹은 세대수 보조데이터 필요).
7. **평형·유형 발산 비교** (IMG_4207/4208/4230/4226) — 권역비교 라인 오버레이(강남/노원/서울평균) + 격차배수, 아파트 vs 빌라 상승률, 소형 선도. (장기추세는 2년 슬라이스 한계 명시)
8. **단지추천 가중치 재보정** (IMG_4221) — 설문 순위(교통>직주>신축)로 관점 가중 재조정 + **입지 접근성 점수**(지하철·3대 업무지구 거리) 신설.

### Tier 3 — 외부 데이터 필요
9. **전세 실질상승 레이어** (IMG_4211) — 전세가율 히트맵에 CPI 차감 "실질 전세상승" 레이어. CPI 상수/외부 API.
10. **청년 인구 증가율 배지** (IMG_4220) — 서울 열린데이터 1회 적재 → 신혼 유망지 배지/정렬. 거래활성도 증가율과 교차 매칭("인구는 느는데 거래 덜 붙은 저평가 유입지").

## 데이터 제약 (정직하게 명시)
- 한지 실거래는 **2년치(2024-06~2026-06)** → 책의 2006~2025 장기 서사는 **2년 슬라이스로만** 재현. 이평선 24주는 산출 가능하나 크로스 표본이 적어 자치구/권역 집계 권장.
- **소득 데이터 없음** → 부담 계산기는 사용자 입력.
- **공급/착공·인구/세대·CPI·관광 인허가**는 실거래 밖 → 외부 공공데이터(KOSIS/서울 열린데이터/통계청) 연동 또는 상수 필요.
- **세대수 미보유** → 세대당 가액은 평당가×전용면적 근사, 진짜 총 시가총액 랭킹은 세대수 확보 후.
- IMG_4204 단위는 **만원**(억 아님), **세대당** 가치 랭킹(총액 아님).
