# 수익화 활성화 체크리스트

코드 배관은 모두 심어져 있고, 아래 값만 채우면 켜집니다.
**모든 값은 미설정 상태로 배포해도 안전**합니다(관련 UI가 렌더되지 않음).

환경변수는 `.env`(로컬) 또는 Vercel/호스트의 환경변수에 넣습니다.
클라이언트에서 읽으므로 `NEXT_PUBLIC_` 접두사가 필수이며, **변경 후 재빌드/재배포**해야 반영됩니다.

---

## 0. 선행 — 배포 (하드 게이트)

애드센스는 **살아있는 인덱싱 가능한 도메인**이 없으면 신청 자체가 불가합니다.

- [ ] 호스팅 결정 (Vercel 권장 — Next 15 + Cron 궁합)
- [ ] DB 연결 (Neon/Supabase 등 관리형 Postgres → `DATABASE_URL`)
- [ ] 도메인 구매·연결 (`*.vercel.app` 기본 도메인은 승인률·신뢰도 낮음)
- [ ] `robots.txt` / `sitemap.xml` / 개인정보처리방침·이용약관 페이지 (← 다음 세션 예정, 애드센스 승인 요건)

## 1. 구글 애드센스

- [ ] 배포 후 애드센스 가입 → 사이트 등록 → 심사 신청 (승인까지 **수일~수주**)
- [ ] 승인되면 게시자 ID를 `NEXT_PUBLIC_ADSENSE_CLIENT`에 입력 (예: `ca-pub-0000000000000000`)
- [ ] 광고 단위 생성 → 슬롯 ID를 `NEXT_PUBLIC_ADSENSE_SLOT_SIDEBAR`에 입력 (예: `1234567890`)
- [ ] **`ads.txt`를 도메인 루트에 배치** (없으면 "수익 손실 위험" 경고 + 수익 보류)
  - 내용 한 줄: `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
  - ⚠️ 게시자 ID는 `ca-pub-...`이지만 ads.txt에는 **`ca-`를 뗀 `pub-...`**을 씀
  - `public/ads.txt`로 정적 배치하거나, env를 읽는 라우트로 생성
- [ ] 소유 확인이 스크립트로 실패하면 메타태그/ads.txt 방식으로 대체
- 자동으로 우측 사이드바에 광고 노출. 다른 위치는 `광고_슬롯` 컴포넌트를 원하는 페이지에 추가.

## 2. 쿠팡 파트너스 (신혼가전·이사·인테리어 한정)

- [ ] partners.coupang.com 가입·승인
- [ ] 상품/검색결과 "링크 생성"으로 내 추적ID 포함 딥링크 발급
- [ ] `src/config/쿠팡_상품.ts`의 각 항목 `링크: ""`에 붙여넣기 (제목·설명 자유 수정)
- 링크가 하나라도 채워지면 홈 "신혼집 준비" 섹션 + 필수 고지가 자동 노출.

## 3. 카카오톡 채널 (광고 없이 이용 · 구독 문의)

- [ ] 카카오톡 채널 개설 → 채널 URL 확인 (예: `https://pf.kakao.com/_xxxxx`)
- [ ] `NEXT_PUBLIC_KAKAO_CHANNEL_URL`에 입력
- 푸터에 "광고 없이 이용 · 구독 문의" 링크 자동 노출.
