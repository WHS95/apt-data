# 인사이트 → 화면 표현 계획 (구현 전 검토용)

> ✅ "현재 실거래 데이터만으로 가능" 8종 중 가치×난이도 우선순위대로, **기존 화면 어디에 · 어떻게 그릴지** 목업으로 정리. 새 페이지 최소화, 기존 화면에 녹이는 방향.

## A. 신고가 대표성 배지 — 단지상세 `/picks/detail` [난이도 낮음 · 최우선]
**위치**: 기존 stats 4칸 그리드에 '대표성' 카드 추가 + 거래추이 차트에 이상치 표시.
**데이터**: 이미 보유(거래금액·계약일자·이상치 로직). 최고가 vs 중위, 최근 90일 건수.

```
[ 최근 1개월 매매 ] [ 역대 최고가 ] [ 전세가율 ] [ ⚠ 대표성 체크 ]
                                                ┌────────────────────────┐
   역대 최고가 15.8억  ←────────────────────────│ 최고가는 최근 90일 중 1건 │
   2024.09·84㎡·32층                            │ 중위가 대비 +38% ‘허수’주의│
                                                │ 신뢰가(중위) 11.4억·8건   │
                                                │ 중위 ●──────────○ 최고    │
                                                └────────────────────────┘
거래추이 차트: 이상치 거래 = 빨강 中공점(◌), 추세선은 중위 기준(신고가에 안 끌림)
```
**메시지**: 신혼부부에게 "미디어 신고가에 휘둘리지 마세요" — 페르소나 정합.

## B. 이동평균 상승신호 (골든/데드크로스) — 서울지도 `/seoul-map` [난이도 중 · 책 시그니처]
**위치**: 지표 셀렉터에 5번째 "🔺상승신호" 추가 + 고정 카드에 미니 이평선.
**데이터**: 자치구 월별 평당가 → 3개월(단기)·12개월(장기) 이동평균 → 교차 탐지. (구×월 밀도 평균 235건, 실측 충분)

```
[매매평당가][전세가율][가격변화(%)][거래활성도][🔺상승신호]
─────────────────────────────────────────────
지도: 골든크로스 구 = 빨강 + 🔺,  데드크로스 = 파랑 + 🔻,  |스프레드|로 농도
     (단기선이 장기선 위=상승진입, 아래=하락)

구 클릭 카드:
┌ 노원구 · 상승신호 ─────────────┐
│ 🔺 골든크로스 (2026-03 발생)    │
│  단기 3M  ▁▂▄▆█  ↗             │
│  장기 12M ▁▁▂▃▄                │
│  스프레드 +4.2% (단기>장기)     │
│  → 상승 초입 신호               │
└────────────────────────────────┘
```
**확장(2단계)**: 단지상세 거래추이 차트에도 단기·장기 이평선 오버레이 + 크로스 마커. 단지추천 '모멘텀' 점수에 크로스 상태 반영.

## C. 권역·평형별 상승률 발산 — 권역비교 `/region` [난이도 중]
**위치**: 기존 시군구 랭킹 테이블 위에 '라인 비교' 섹션 추가.
**데이터**: 권역 프리셋별 분기 평당가 지수(2년 슬라이스) + 평형/유형 토글. (빌라 68k건 실측 충분)

```
권역 비교
[프리셋: 강남3구 | 강북3구 | 서울평균]   평형[20평|30평]   유형[아파트|빌라]
───────────────────────────────────────────────────────
평당가 지수 (2024Q3 = 100)
 130┤                       ╭── 강남3구
 115┤             ╭─────────╯
 100┼─────────────
  90┤          ╰────── 서울평균 · 강북3구
     24Q3   Q4   25Q1   Q2   Q3   Q4   26Q1   Q2
격차배수: 강남3구 / 서울평균 = 1.7배  (최근 6개월 +0.2)
아파트 vs 빌라: 아파트 +25% / 빌라 +12%  → 격차 2배

▼ (아래) 기존 시군구 랭킹 테이블 그대로 유지
```

## D. 예산 → 평균 연식 — 예산매물 `/budget` [난이도 낮음]
**위치**: 예산매물 결과 상단 배지 + (선택) 매트릭스 카드.
**데이터**: 가격구간×평형별 건축연도 중위. (건축연도 결측 0% 실측)

```
예산 9억 입력 → "이 예산이면 서울 20평대 평균 2004년식(21년차)" 배지

가격대\평형   20평   30평   40평
  5억대      1990   1988   1985      (색: 신축=진한 초록)
  7억대      2002   1999   1996
  9억대      2004   2003   2001
```

## E. 주거 부담 계산기 — 예산매물 `/budget` [난이도 중]
**위치**: 예산 입력부 확장(연소득·LTV·금리 입력 → 월 상환액 → 상환가능 매물 필터).
**데이터**: 실거래 매물 + 사용자 입력(외부 데이터셋 불필요).

```
[ 연소득 ___억 ] [ LTV __% ] [ 금리 _._% ] [ 기간 _년 ]
→ 월 원리금 253만 · 이자만 177만 · 상환가능 상한 8.9억
→ 아래 매물 리스트를 '상환가능'만 필터
```

**A(신고가 배지) → B(상승신호) → C(권역·평형) → D(연식)** — A는 기존 이상치 재사용으로 가장 빠르고, B는 책의 핵심 차별화.

# ▶ 확정 진행: 골든크로스 뷰 (서울 구별 · 기간선택 · 주식차트) — 화면 계획

> B를 "골든크로스만" 좁혀서 먼저. 서울 25개 구를 하나씩, 주식차트처럼 평당가 + 단기·장기 이평선 + 골든크로스 마커로 본다.

## 화면 목업
```
┌─ 골든크로스 · 서울 구별 ─────────────────────────────────────┐
│  구 [노원구 ▾]                     기간 [ 1년 | 2년 | 전체 ]  │
│──────────────────────────────────────────────────────────────│
│  노원구 평당가 (만원/평)                  현재 🔺 골든크로스   │
│ 3,400┤                               ╱╲                        │
│ 3,200┤                      ╱‾‾‾╲___╱  ╲── 단기(8주)          │
│ 3,000┤              🔺__ ╱             ╲── 장기(24주)         │
│ 2,800┤       ╱‾‾‾‾‾╱   ▲골든크로스                            │
│ 2,600┤ __╱‾‾‾  ▽데드                                          │
│      └──┬─────┬─────┬─────┬─────┬─────┬─────┬──               │
│       25.01   03    05    07    09    11  26.01              │
│  ─ 평당가(주별 중위)   ━ 단기 8주   ━ 장기 24주   ▲골든 ▽데드 │
│──────────────────────────────────────────────────────────────│
│  최근 골든크로스 2026-03-w2 · 스프레드 +4.2%(단기>장기) 유지중 │
│  ▾ 전체 구 스캔(선택): 현재 골든크로스 6개 구 — 강북·성북·노원…│
└──────────────────────────────────────────────────────────────┘
```

## 구성 요소
- **구 선택**: 서울 25개 구 드롭다운(또는 칩). 선택 시 해당 구 차트 갱신.
- **기간 선택**: `1년 | 2년 | 전체` (X축 표시 범위 = 줌). 데이터가 2년이라 전체=2년.
- **주식차트(라인)**: X=주(week), Y=평당가 중위(만원/평).
  - 3개 선: ① 평당가 주별 중위(얇게) ② 단기 이평선 8주(굵게) ③ 장기 이평선 24주.
  - **골든크로스 마커 ▲(금색)**: 단기선이 장기선을 아래→위로 돌파한 주. (데드크로스 ▽는 회색·연하게, 맥락용 — 골든 우선)
  - hover 시 크로스헤어 + 툴팁(날짜·평당가·스프레드).
- **상태 요약**: 현재 골든/데드 여부, 최근 골든크로스 발생 주, 스프레드(단기−장기 %).
- **(옵션) 전 구 스캐너**: 현재 골든크로스 발생 구 목록 — "구별로 훑기" 보조.

## 데이터 계산 (구현 시)
- **주별 평당가 중위**: 구별·ISO주별 `percentile_cont(0.5)`(거래금액 ÷ (면적/3.305785)), 매매·아파트·해제제외·완결창. (서울 구×월 평균 235건 → 주별도 표본 충분)
- 거래 없는 주는 직전값 유지(step) 보간.
- **단기 8주 / 장기 24주 이동평균**(책 7·24주에 근접). 2년≈104주라 장기 24주 산출 후 ≈80주에서 크로스 탐지 가능.
- **골든크로스 판정**: `단기[t-1] ≤ 장기[t-1]` and `단기[t] > 장기[t]`.
- **스프레드**: (단기−장기)/장기 ×100.
